sublime个人PHP开发配置

一. 配置php编译环境
Sublime Text 3\Data\Packages 目录下新建 PHP.sublime-build 文件，内容如下：

{
    "cmd": ["D:\\web\\php\\php.exe", "$file"],
    "file_regex": "^(...*?):([0-9]*):?([0-9]*)",
    "path": "D:\\web\\php\\",
    "selector": "source.php"
}

六. 修改默认配置
首选项-> 配置-用户，添加以下：

    "auto_close_tags": false,                     //标签自动闭合 -- 写html最烦这个自动标签
    "auto_complete": true,                        //提示并自动完成 -- 默认也是这个
    "auto_complete_commit_on_tab": false,        //用了这个提示的内容不能用enter选择 只能用tab -- 不习惯
    "auto_indent": true,                        //自动缩进
    "auto_match_enabled": false,                //自动匹配引号
    //"color_scheme": "Packages/theme/Notepad++.tmTheme",  //选择主题，将Notepad++.tmTheme放在Sublime Text 3/Data/Packages/theme/目录下
    "default_encoding": "UTF-8",                //默认字符
    "fallback_encoding": "UTF-8",                // 编码时不能自动检测编码时，将自动检测ASCII, UTF-8 和 UTF-16
    "font_face": "Courier New",                    //字体 -- notepad默认字体
    "font_size": 15,                            //字号
    "highlight_line": true,                        //突出显示光标所在行
    "line_padding_bottom": 1,                    //下行距
    "line_padding_top": 1,                        //上行距
    "tab_completion": false,                    //tab自动选择并完成---最烦的 覆盖了缩进
    "update_check": false,                        //不检查更新
    "word_separators": "./\\()\"'-:,.;<>~!@#%^&*|+=[]{}`~?",//单词匹配$号，与WordHighlight插件一起使用能双击选择PHP带$的变量,并高亮其他相同单词
    "word_wrap": true                            //自动换行
